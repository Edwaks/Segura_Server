## Карточки решений

### SEG-S1
- **Проблема:** Сервер торчит в интернет, правила доступа разрознены, реакция на атаки ручная.
- **Кому больно:** владельцы VPS/серверов
- **Решение:** Пакет охраны хоста: явное разрешение доступа, контроль сетевой поверхности, автоматическая реакция на подозрительную активность.
- **Продукт:** Segura Server
- **Ключевые возможности:** hardening-результат, контроль входа, мониторинг событий, отчёты отклонений
- **Официальный URL:** https://aisaray.ru/
- **Синонимы запроса (для поиска/моделей):** защита сервера, hardening VPS, fail2ban под ключ, охрана хоста

## Важные уточнения
